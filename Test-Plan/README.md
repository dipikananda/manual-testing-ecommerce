# Manual Testing – E-Commerce Website

## Project Overview

This is a manual testing project for an e-commerce web application.

The project demonstrates the complete Software Testing Life Cycle (STLC), including test planning, test scenario creation, test case design, test execution, defect reporting, and test summary reporting.

**Application Under Test:** SauceDemo  
**Testing Type:** Manual Testing  
**Application Type:** Web Application

---

## Testing Scope

The following modules are covered:

- Login
- Products
- Product Sorting
- Shopping Cart
- Checkout
- Order Confirmation

---

## Testing Types

- Functional Testing
- UI Testing
- Smoke Testing
- Regression Testing
- Sanity Testing
- Negative Testing
