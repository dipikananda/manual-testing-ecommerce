### Examples

- **Positive Testing:** Valid login, valid checkout information, and successful order placement.
- **Negative Testing:** Invalid login credentials and blank mandatory checkout fields.
- **UI Testing:** Product names, descriptions, prices, images, buttons, and confirmation messages.
- **Validation Testing:** Required First Name, Last Name, and Postal Code validation.
- **Navigation Testing:** Cancel, Continue Shopping, and Back Home functionality.
- **Data Verification:** Product prices and order-summary information.
- **Calculation Verification:** Item total, tax, and final order total.
- **End-to-End Testing:** Complete customer journey from login through order confirmation.
